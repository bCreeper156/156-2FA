156-2FA API 文档载入中…

前端与后端完全分离：所有数据都通过下列 REST 接口获取，密钥与口令不会出现在任何响应中。 机器可读规范：/api/openapi.json。

鉴权方式

推荐 Authorization: Bearer <accessToken>：远程 / 第三方客户端使用，不受来源限制。
桌面端 Cookie 2fa_frontend 或 URL 参数 ?token=：桌面窗口会话，受 Host / Origin 白名单保护。
跨域调用已内置 CORS 预检支持。

出错时统一返回 { "ok": false, "error": "原因" } 及对应状态码：400 参数错误、403 无权限、404 资源不存在、500 服务端失败。
